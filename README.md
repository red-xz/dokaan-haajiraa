# দোকান হাজিরা (Dokaan Haajiraa)

Employee attendance + salary app for shops. Live at https://dokaan-haajiraa.web.app

- Employees join with the admin's unique 6-letter shop code
- GPS check-in (only within 100m of the shop)
- Monthly salary set by admin; salary ÷ 30 = daily wage; absent/leave unpaid; Friday is the paid weekly holiday
- Multi-shop: anyone can create their own shop (separate code + data)
- Firebase: Firestore (asia-southeast1) + Anonymous Auth + Hosting, Spark plan
- No sign-in needed for employees — open the link in the phone browser
